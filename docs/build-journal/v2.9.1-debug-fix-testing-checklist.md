## Failure Actions

### If Test Fails:
1. Check browser console for errors
2. Check Network tab for failed requests
3. Check `<body>` element style attribute
4. Verify dev server is running
5. Try hard refresh (Ctrl+Shift+R)

### Common Issues:
- **"streamCleanupRef is not defined"** → VoiceUI missing ref declaration
- **Infinite "Processing..."** → Missing status update in error path
- **UI frozen** → document.body.overflow not restored
- **No orchestration logs** → orchestrateCommand not called
