## 🧠 Core Components

### Memory Service (`memoryService.ts`)
Persistent context and entity storage with semantic search capabilities.

**Key Features**:
- Agent profiles with preferences and branding
- Property records with market data  
- Generated artifacts with quality metadata
- Semantic embedding-based recall
- Context summarization for AI prompts

**Usage**:
```typescript
import { memoryService } from './services/v3/memoryService';

// Store agent profile
await memoryService.upsertAgent({
  id: 'agent_001',
  name: 'Sarah Johnson',
  specialties: ['Luxury properties'],
  voice_preferences: { tone: 'professional' }
});

// Semantic recall  
const relevantMemories = await memoryService.recall('luxury property downtown', { limit: 5 });
```

### Content Engine (`contentEngine.ts`)
AI-powered content generation with context awareness and quality validation.

**Generation Pipeline**:
1. Context building with memory enrichment
2. Dynamic prompt assembly with structured data
3. Multi-pass generation (draft → critique → revision)
4. Quality validation and scoring
5. Artifact storage for future reference

**Usage**:
```typescript
import { contentEngine } from './services/v3/contentEngine';

const result = await contentEngine.generateContent({
  session_id: 'session_123',
  content_type: 'CMA_REPORT',
  user_prompt: 'Create a CMA for 123 Main Street',
  memory_context: memoryContext
});
```

### Validation Pipeline (`validationPipeline.ts`)
Comprehensive content quality assurance with automated remediation.

**Validation Checks**:
- Grammar and spelling verification
- Reading level assessment (Flesch-Kincaid)
- Brand voice alignment scoring  
- Fair housing compliance verification
- Template fit validation
- Content length constraint validation

**Usage**:
```typescript
import { validationPipeline } from './services/v3/validationPipeline';

const report = await validationPipeline.validatePostGeneration({
  content_type: 'CMA_REPORT',
  generated_content: content,
  brand_kit: brandKit
});
```

### Template Renderer (`templateRenderer.ts`)
Converts structured content into pixel-perfect branded outputs.

**Rendering Features**:
- Content-to-slot binding with overflow detection
- Typography enforcement with font fallbacks
- Brand color and logo application
- Multi-format output (HTML, PDF-ready, PPTX-ready)
- Responsive breakpoint handling

**Usage**:
```typescript
import { templateRenderer } from './services/v3/templateRenderer';

const result = await templateRenderer.render({
  template: cmaTemplate,
  content: generatedContent,
  brand_kit: brandKit,
  export_format: 'html'
});
```

### Brand Kit Service (`brandKitService.ts`)
Brand asset management and enforcement system.

**Brand Management**:
- Color palette management with accessibility compliance
- Typography enforcement with font licensing
- Logo management with usage guidelines
- Voice and tone consistency validation
- Compliance rule enforcement

**Usage**:
```typescript
import { brandKitService } from './services/v3/brandKitService';

// Create brand kit
const brandKit = await brandKitService.createBrandKit({
  name: 'Premium Real Estate Brand',
  colors: colorSystem,
  typography: typographySystem
});

// Apply to content
const result = await brandKitService.applyBrandKit(brandKit.id, content);
```

### Export Service (`exportService.ts`)
High-fidelity document generation and multi-format export.

**Export Formats**:
- **PDF**: Print-ready with embedded fonts and vector graphics
- **PPTX**: PowerPoint with master slide inheritance
- **PNG/JPG**: Social media optimized images
- **HTML**: Web-ready with optimized assets

**Usage**:
```typescript
import { exportService } from './services/v3/exportService';

const result = await exportService.exportContent({
  content_id: 'content_123',
  format: 'pdf',
  options: exportService.optimizeExportSettings('pdf', 'print'),
  output_preferences: { orientation: 'portrait' }
});
```

### Enhanced Follow-up Agent (`enhancedFollowupAgent.ts`)
Intelligent next-step recommendations based on content and context.

**Recommendation Types**:
- High-impact primary tasks with success metrics
- Optional enhancement activities
- Multi-content marketing campaign opportunities
- Workflow automation suggestions
- Content gap analysis and recommendations

**Usage**:
```typescript
import { enhancedFollowupAgent } from './services/v3/enhancedFollowupAgent';

const recommendations = await enhancedFollowupAgent.generateFollowUpRecommendations({
  task_id: 'task_123',
  content_type: 'CMA_REPORT',
  generated_content: content,
  agent_profile: agentProfile
});
```
