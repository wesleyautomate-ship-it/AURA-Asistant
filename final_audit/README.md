## Final Audit Overview

This folder captures the open gaps that prevent the “marketing intelligence” experience from running end-to-end in a local dev environment. Each Markdown file highlights the blockers per feature:

- `auth.md` – Login/session flow, JWT issues, dev bypass alignment.
- `brochure.md` – Property brochure enrichment, PDF rendering, AI fallback.
- `cma.md` – CMA report data, orchestration stubbing, front-end contract.
- `marketing.md` – Template/campaign persistence, AI dependency, asset generation.
- `social.md` – Social automation tables, AI fallback, response contracts.
- `analytics.md` – Dashboard metrics data, cache behavior, RBAC.
- `workflows.md` – Task orchestration infrastructure, workflow seeds, SSE streaming.
